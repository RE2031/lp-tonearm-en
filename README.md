# Tonearm

An interactive vinyl player that plays YouTube tracks. Click the record, drag the tonearm, or use webcam hand gestures to start playback.

[Open the English site](https://re2031.github.io/lp-tonearm-en/)

To run locally, start `python -m http.server 8080` and open `http://localhost:8080`. Camera access requires HTTPS or localhost.
